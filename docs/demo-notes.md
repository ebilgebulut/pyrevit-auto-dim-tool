# Demo Notes

This folder contains example screenshots and testing notes for the pyRevit Auto Dim Tool.

## Current Demo Scope

The current demo version includes:

- Grid segment dimensions
- Grid overall dimensions
- Facade dimensions
- Facade overall dimensions
- Multiple selected plan views
- Offset and placement order control
- Revit 2025 / 2026 compatibility testing

## Tested Conditions

The tool has been tested on:

- Orthogonal building layouts
- Multi-level plan views
- Standard Revit walls and grids
- Basic door and window openings

## Known Limitations

- Curved walls are not fully supported
- Complex joined wall conditions may require additional testing
- Some custom family references may behave differently
- Performance may vary depending on project size
